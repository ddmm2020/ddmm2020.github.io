🔨 Projects

  • ZeroRL: Synchronous / Asynchronous RL Training Runtime Scheduling 2025.12 - 2026.04
    VeRL RL / Post-training Infra

    A runtime scheduling system for RL training that abstracts the training process into instruction descriptions（RL Compiler）, enabling flexible instruction-based adjustments to eliminate idle time in synchronous training. Achieved ~20% throughput improvement over VeRL's colocated synchronous approach and ~12% over fully asynchronous methods (StreamRL).

  • ECCL: Efficient Model State Online Migration for Elastic Training of Large Language Models 2024.10 - 2025.09
    Collaboration with Huawei 2012 Lab, High-Performance Network Lab Megatron-LM AI Infra (Elasticity / Fault Tolerance)

    A high-performance elastic training migration system that minimizes data transfer by exploiting locality between pre- and post-elasticity parallel strategies. Achieved 2.33x-6.37x speedup over checkpoint-based methods, reducing migration overhead from minutes to seconds.

  • Mario: Low-Cost Activation Checkpointing in Pipeline Parallelism 2023.11 - 2024.09
    Published at PPoPP 2025 (CCF-A) Megatron-DeepSpeed Pre-training Infra

    A system that leverages pipeline bubbles to perform near zero-cost activation checkpointing in large model parallel training. Achieved 1.16x-1.52x speedup over the baseline without gradient checkpointing.
